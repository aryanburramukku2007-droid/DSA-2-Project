# Data Structures and Algorithms - II Case Studies

## 📚 Overview

This repository contains a collection of academic case studies designed for **Data Structures and Algorithms - II**. The case studies focus on practical applications of advanced data structures and graph algorithms through real-world scenarios.

The document covers:

* Binary Search Trees (BST) and AVL Trees
* Segment Trees and Fenwick Trees
* Minimum Spanning Trees (Kruskal's and Prim's Algorithms)

Each case study follows a **15-mark university examination pattern** and includes:

* Real-world problem scenario
* Algorithmic analysis
* Diagrams and visual representations
* Step-by-step solutions
* Complexity discussion
* Pseudocode implementations

## 📖 Case Study 1: BST and AVL Tree Indexing

### Scenario

A hospital maintains a patient-ID dictionary for fast triage lookups. The system must remain efficient even when patient IDs arrive in nearly sorted order.

### Concepts Covered

* Binary Search Tree Construction
* AVL Tree Balancing
* LL, RR, LR, RL Rotations
* Lookup Performance Analysis
* Tree Height Calculation
* AVL Deletion Operations

### Learning Outcomes

* Construct BST and AVL Trees
* Analyze lookup efficiency
* Perform AVL rotations
* Maintain balanced search structures

---

## 📖 Case Study 2: Segment Tree Range Queries

### Scenario

A smart warehouse stores rack sensor readings and requires efficient range-sum queries and point updates.

### Concepts Covered

* Segment Tree Construction
* Range Sum Queries
* Point Updates
* Query Optimization
* Segment Tree vs Fenwick Tree
* Time Complexity Analysis

### Learning Outcomes

* Build Segment Trees
* Perform range queries efficiently
* Update tree structures dynamically
* Compare advanced range-query data structures

---

## 📖 Case Study 3: Minimum Spanning Tree for Network Design

### Scenario

A university plans a fiber-optic network connecting multiple campus buildings with minimum installation cost.

### Concepts Covered

* Weighted Graph Representation
* Kruskal's Algorithm
* Edge Sorting
* Cycle Detection
* Minimum Spanning Tree Construction
* Network Cost Optimization

### Learning Outcomes

* Apply MST algorithms
* Analyze graph connectivity
* Optimize network design
* Compare alternative edge selections
